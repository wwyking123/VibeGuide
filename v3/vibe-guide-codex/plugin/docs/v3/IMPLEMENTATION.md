## 技术与产品取舍

1. 复用原有 GuideStore 和工具跟踪，新增 v3 服务、任务与证据契约、访谈／诊断／回顾规则及三入口 UI。未重写所有旧模块；旧通信服务仅作为源代码回归对象，不挂载到新版运行时。
2. 旧记录读写格式保留，v3 任务使用独立命名空间，不把旧要求自动转成用户已确认的新任务，也不恢复旧发送队列。没有将所有旧历史迁成新任务的向导。
3. 一个会话一次跟随一个任务。新任务封存旧任务范围；历史任务不能重新扩展到后续会话内容，需要新建任务继续。
4. 当前草稿填入能力关闭，所有转交使用完整可见文本复制。用户在主聊天中自行发送。
5. 划词默认作为当前窗口中的引用材料；能明确提供消息引用时服务端校验。DOM 选区未映射到宿主消息 ID 时，不伪造出处。解释不会执行选区中的指令。
6. 自动诊断每任务最多 5 次，自动回顾最多 2 次，人工请求另计；沿用旧适配器的模型用量限制。设置中可以关闭自动能力。
7. 任务范围内保留有限的证据、操作和生成历史。超长或缺失记录明确标为不完整；首版不是永久完整审计系统。

## 验证记录

- 原始基线：109 项测试通过。
- 新版：125 项测试通过，包括访谈、并发版本、幂等、无目录关联、同会话任务隔离、问题恢复、人工反馈更新、回顾来源、自动调用预算与删除晚到等。
- 真实环境：macOS，DSH Desktop 0.12.1，内部 Harness 0.2.1-rc.2。
- 隔离宿主：验证插件安装／升级、认证网关、工具真实执行失败、自动诊断、回顾来源、主聊天无写入、卸载／重载与持久化恢复。固定模型回答，无真实提供商费用。
- 已安装包副本：复制到临时环境复测，不修改该副本及用户的日常配置。
- 浏览器 UI：在相同 DSH 客户端检查三入口、失败卡片、主消息拖选、独立解释小窗及回顾页面。截图是测试任务，不是用户真实项目。

## 本机安装与回退

已更新用户现有 DSH Desktop 的 web profile；与旧版采用相同插件 ID 和独立版本副本。安装器保留原始 cordis.patch.yml 备份及旧插件文件，未改动模型设置。应用未被强制退出，需用户在空闲时完全退出并重开后使用新版。

安装回执详见 VibeGuide-Local-Installation.json。回退时先关闭应用，将回执 backup 文件恢复到 profile/cordis.patch.yml，再重新打开。数据清理不要删除项目或主会话。
