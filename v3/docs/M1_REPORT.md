### 集成中发现并修好的问题

单元测试都没能发现这几个问题。

1. **侧栏「开始」页整页崩溃（UI-1）。** 登记入口时把 `description` 写成了字符串，宿主要求的是函数，结果宿主自己的开始页渲染失败。已改为函数，并在代码里注明。
2. **深色模式下主按钮看不见。** 宿主的品牌主色在深色模式下是白色，按钮成了白底白字。改用宿主的按钮配色对：`--dsw-alias-button-primary-fill` 搭配 `--dsw-alias-label-primary-foreground`。
3. **侧栏收起后不出提示条。** 宿主没有给插件"侧栏展开状态变化"的事件。改为有阻断卡时每 0.7 秒检查一次。
4. **标签红点被截掉。** 标签宽度不够时，标题末尾会被截断，红点在末尾所以看不到。改为放在标题前面。
5. **模型自己默认的"不需要外部服务"被算进了"已确认"（F1-6）。** 已修改提示词：用户没说过的内容一律标为推断，所以会进"暂定"。

另外，单元测试阶段发现并修复了一个死锁：会话补读时，预警模块要读项目信息，而读项目信息又要等补读完成。
