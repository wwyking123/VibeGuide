# 活动报名本机演示

已有的极小项目，用来试用 AI 连续修改与换会话续接。使用 Node.js 22 或更高版本；没有 npm 依赖、密钥或外部服务。

```sh
node server.mjs --port 4173
```

打开终端给出的本机地址，填写虚构姓名和邮箱，提交后切换“组织者演示页”查看名单。刷新同一地址会读取这个浏览器保存的演示报名。按 Ctrl+C 停止服务。

初始行为：没有人数上限，重复邮箱不重复保存；参加者页面不展示名单，组织者演示页展示名单。没有真实登录或访问权限，任何能操作此浏览器的人都能切换视角。这里的页面分区不能证明名单安全。

数据只在当前浏览器的 localStorage 中，不写入服务器、不跨浏览器共享，也不具备多人并发名额保障。请勿填写真实个人信息。组织者演示页中的“演示数据操作”可以明确确认后替换为 19 条虚构报名，或清空名单；它们不会删除 AI 的项目记忆。

文件：`registration.mjs` 处理报名，`app.mjs` 处理页面与本机存储，`style.css` 控制外观，`server.mjs` 只提供明确列出的页面文件。需要增加浏览器资源时须更新服务器的文件列表，不应把整个项目目录公开。

这是无外部依赖的试用材料，不是产品推荐技术栈，也不是可上线的报名服务。浏览器视觉效果、真实用户理解和模型行为需要另外观察。
