# DeepSeek Harness × VibeGuide 集成原型

> 此原型为旧方向对照材料：用户已反馈侧栏解释不符合预期。最新方向是 [让原生 AI 回答直接可理解](../docs/CONVERSATION_FIRST_DESIGN.md)，本 HTML 尚未据此重做。

用现代浏览器打开 [index.html](index.html)。单文件包含 HTML、CSS、JavaScript 和公司网站示意，无需安装依赖或联网。这是宿主内插件的交互概念，并未运行或安装真实 DeepSeek Harness 插件。

## 推荐体验

1. 默认进入“回答问题”场景：中间保留 Harness 的技术原文，下方是原生问题，右侧解释“以后谁来更新网站内容”。
2. 在右侧选择“同事需要自己更新内容”，观察原生问题同步改选。两边操作同一份候选答案；选择本身不会发送。
3. 点击原生问题的“模拟发送回复”。侧栏没有第二个发送按钮，已回答的问题锁定为只读，可以展开原问题与全部选项。
4. 选择“都不符合”，在原问题中描述自己的要求。你的原话保留为自定义答案，不会强行匹配现有选项。
5. 关闭左下角 VibeGuide 开关：原生问题、草稿、会话输入框和网站预览仍能使用。重新启用后点击解释入口打开侧栏。
6. 用最上方的演示控制切换方案、成果与验收场景，打开预制公司页面，切换宽窄屏并记录人工检查。

发送后可以“开启一轮新的需求确认”，重新体验选择。修改目标或开启新问题时，旧决定和检查记录会被标记为旧版本。

## 页面与交互归属

| 区域 | 归属与行为 |
| --- | --- |
| 顶部蓝色演示控制条 | 原型专用场景选择器，不是 Harness 或 VibeGuide 的产品导航，不推进真实任务 |
| 左侧工作区与会话 | DeepSeek Harness 外壳示意；没有 VibeGuide 独立项目管理或五步导航 |
| 中间原会话 | 保留技术消息、原问题和原始选项，问题卡位于输入区；回答后恢复普通输入框 |
| 右侧 VibeGuide 标签 | 按需解释计划、选项影响、目标与结果，没有独立聊天输入框 |
| 原问题的发送按钮 | 唯一的提问回复入口；白话选择、原始选择和自定义草稿共享状态 |
| 预览窗口 | 预制网站示意，独立于插件启用状态 |

默认展开侧栏只是为了展示效果；实际产品按需打开。窄屏时侧栏覆盖部分会话，“到原问题回复”会先收起侧栏；侧栏展开期间键盘焦点保持在其中，可用 Esc 关闭。关闭插件不清空宿主草稿或替用户回答问题。

没有调用模型、读取或生成项目、执行自动测试或部署。文件树、技术问题、解释、进度与公司网站均预先编写。任意新增需求不会自动改变预制方案和网页。更换场景不代表任务完成。

输入和检查记录保存在当前浏览器的 localStorage；禁用本地存储时仍可在本次页面体验，刷新不保留。在“目标与决定 → 重置本地演示”或“使用说明 → 重置演示”恢复初始状态。
