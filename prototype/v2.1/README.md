# VibeGuide v2.1 交互原型

这是根据产品文档与技术设计制作的独立 HTML + SVG 原型，不是已安装的 Harness 插件。没有真实模型调用、消息投递、代码修改或服务接入；记录仅在页面内存中，刷新或重置会清空。

- `index.html`：可直接用浏览器打开的单文件交互原型。
- `overview.svg`：可缩放的静态前端与交互总览。

## 体验路径

1. 从零开始：在主对话选择问题来源和保存范围，点击“按这两个选择开始”。
2. 在侧栏点击“为什么不用云端保存？”，体验提问留在侧栏。
3. 主线产生新进展时，阅读位置保持，并出现“回到最新”。演示工具栏可手动“推进一步”或关闭自动演示。
4. 点击或输入完整示例“那就改成换手机也能看”，直接转交并显示演示回执；重复点击不会重复投递。
5. 点击“项目结构”中的 SVG 节点，查看职责与影响；“了解过的”可以重新打开历史说明，并提示依据变化。
6. 切换“接手项目”“途中卡住”，体验咨询表单与保存失败的不同解释。各场景重置自己的演示状态。

窄屏通过顶部面板按钮在主对话和侧栏间切换。SVG 节点支持 Tab 和 Enter，页签支持方向键，输入框支持 Command/Ctrl + Enter。

自由输入仅识别少量预设表达；未覆盖内容会明确提示原型范围，不模拟任意问题都能得到正确回答。含糊表达示例：“这样不太合适”。预览里的输入只存在页面内存中。

无需安装依赖。也可在项目根目录运行：

```sh
python3 -m http.server 4391 --bind 127.0.0.1 --directory prototype/v2.1
```

然后打开 `http://127.0.0.1:4391/`。正式客户端与宿主接入仍按技术文档实施。
